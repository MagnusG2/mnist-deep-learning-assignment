# MNIST Deep Learning Assignment

## Περιγραφή εργασίας

Η παρούσα εργασία υλοποιήθηκε στο πλαίσιο του μαθήματος **Τεχνητή Νοημοσύνη** και αφορά την εφαρμογή τεχνικών Βαθιάς Μάθησης για την ταξινόμηση χειρόγραφων ψηφίων του συνόλου δεδομένων **MNIST**.

Στόχος της εργασίας είναι η εκπαίδευση και αξιολόγηση νευρωνικών δικτύων που δέχονται ως είσοδο εικόνες χειρόγραφων ψηφίων μεγέθους **28x28 pixel** και προβλέπουν την αντίστοιχη κλάση από το **0 έως το 9**.

Η εργασία περιλαμβάνει:

- Προεπεξεργασία των δεδομένων MNIST.
- Εκπαίδευση πλήρως συνδεδεμένων Deep Neural Networks.
- Πειραματισμό με διαφορετικές υπερπαραμέτρους.
- Υλοποίηση βελτιωμένης αρχιτεκτονικής με Convolutional Neural Network.
- Σύγκριση αποτελεσμάτων και τελική αξιολόγηση.

---

## Dataset

Χρησιμοποιήθηκε το dataset **MNIST**, το οποίο περιλαμβάνει ασπρόμαυρες εικόνες χειρόγραφων ψηφίων. Κάθε εικόνα έχει διαστάσεις **28x28x1** και αντιστοιχεί σε μία από τις δέκα κλάσεις ψηφίων.

Τα δεδομένα χωρίστηκαν ως εξής:

| Σύνολο | Πλήθος εικόνων | Περιγραφή |
|---|---:|---|
| Training set | 50.000 | Χρήση για εκπαίδευση |
| Validation set | 10.000 | Χρήση για επιλογή υπερπαραμέτρων |
| Test set | 10.000 | Χρήση για τελική αξιολόγηση |

Οι τιμές των pixel κανονικοποιήθηκαν στο διάστημα **[0, 1]** διαιρώντας με το 255.

---

## Μεθοδολογία

Αρχικά υλοποιήθηκαν πλήρως συνδεδεμένα νευρωνικά δίκτυα, στα οποία κάθε εικόνα 28x28 μετατράπηκε σε διάνυσμα 784 χαρακτηριστικών. Στη συνέχεια πραγματοποιήθηκε hyper-parameter tuning, δοκιμάζοντας διαφορετικούς συνδυασμούς παραμέτρων.

Οι υπερπαράμετροι που εξετάστηκαν ήταν:

- αριθμός κρυφών επιπέδων,
- αριθμός νευρώνων ανά επίπεδο,
- συνάρτηση ενεργοποίησης,
- learning rate,
- batch size,
- αριθμός εποχών,
- dropout.

Για την εκπαίδευση χρησιμοποιήθηκε ο optimizer **Adam** και η συνάρτηση απώλειας **Sparse Categorical Crossentropy**, επειδή οι ετικέτες του MNIST είναι ακέραιοι αριθμοί και όχι one-hot vectors.

---

## Hyper-parameter Tuning

Δοκιμάστηκαν διάφορες αρχιτεκτονικές πλήρως συνδεδεμένων DNN. Το καλύτερο Dense μοντέλο ήταν:

```text
DNN_512_256_128_relu_lr1e-3
```

με:

- 3 κρυφά επίπεδα: 512, 256 και 128 νευρώνες,
- activation function: ReLU,
- learning rate: 0.001,
- batch size: 128,
- dropout: 0.2.

Το συγκεκριμένο μοντέλο πέτυχε ακρίβεια:

```text
Test Accuracy: 98.11%
```

---

## Βελτίωση με CNN

Ως επιπλέον βελτίωση υλοποιήθηκε ένα **Convolutional Neural Network**. Η επιλογή CNN είναι κατάλληλη για δεδομένα εικόνας, επειδή οι συνελικτικές στρώσεις αξιοποιούν τη χωρική σχέση των γειτονικών pixel και μπορούν να εντοπίσουν τοπικά χαρακτηριστικά, όπως γραμμές, καμπύλες και γωνίες.

Η αρχιτεκτονική του CNN περιλαμβάνει:

- Conv2D layers,
- Batch Normalization,
- MaxPooling,
- Dropout,
- Flatten layer,
- Dense layer,
- Softmax output layer.

Το CNN πέτυχε:

```text
Test Loss: 0.03244
Test Accuracy: 98.96%
```

---

## Τελικά αποτελέσματα

| Μοντέλο | Τύπος | Test Accuracy |
|---|---|---:|
| DNN_512_256_128_relu_lr1e-3 | Fully Connected DNN | 98.11% |
| Improved_CNN | Convolutional Neural Network | 98.96% |

Το CNN είχε καλύτερη απόδοση από το καλύτερο Dense DNN κατά περίπου **0.85 ποσοστιαίες μονάδες**. Αυτό είναι αναμενόμενο, καθώς τα CNN είναι πιο κατάλληλα για προβλήματα εικόνας.
