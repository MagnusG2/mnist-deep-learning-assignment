# 4η Εργασία - Βαθιά Μάθηση στο MNIST

## Στόχος εργασίας
Η εργασία αφορά την εκπαίδευση Βαθιών Νευρωνικών Δικτύων για την ταξινόμηση χειρόγραφων ψηφίων του συνόλου δεδομένων MNIST. Το MNIST περιλαμβάνει ασπρόμαυρες εικόνες 28x28 pixel με ψηφία από το 0 έως το 9. Σκοπός είναι η σύγκριση διαφορετικών υπερπαραμέτρων σε fully connected Deep Neural Networks και η υλοποίηση μιας επιπλέον βελτίωσης για αύξηση της ακρίβειας.

## Περιεχόμενα repository
- `MNIST_Deep_Learning_Assignment.ipynb`: Google Colab notebook με όλο τον κώδικα της εργασίας.
- `hyperparameter_tuning_results.csv`: πίνακας με τα αποτελέσματα των πειραμάτων hyper-parameter tuning, που δημιουργείται μετά την εκτέλεση του notebook.
- `final_model_comparison.csv`: σύγκριση του καλύτερου Dense DNN με το βελτιωμένο CNN, που δημιουργείται μετά την εκτέλεση του notebook.
- `README.md`: σύντομη περιγραφή του έργου και οδηγίες εκτέλεσης.

## Μεθοδολογία
Αρχικά φορτώνεται το MNIST από τη βιβλιοθήκη Keras/TensorFlow και γίνεται κανονικοποίηση των pixel στο διάστημα [0, 1]. Στη συνέχεια δημιουργείται validation set από τα δεδομένα εκπαίδευσης. Για τα fully connected DNN οι εικόνες μετατρέπονται σε διανύσματα 784 χαρακτηριστικών, ενώ για το CNN διατηρείται η μορφή 28x28x1.

Στο πρώτο μέρος πραγματοποιούνται πειράματα hyper-parameter tuning με διαφορετικό αριθμό κρυφών επιπέδων, διαφορετικό πλήθος νευρώνων, διαφορετικές συναρτήσεις ενεργοποίησης, learning rate, batch size και dropout. Για κάθε πείραμα καταγράφονται η καλύτερη validation accuracy, η test accuracy και το test loss.

Στο δεύτερο μέρος υλοποιείται βελτιωμένη αρχιτεκτονική Convolutional Neural Network. Η επιλογή CNN είναι κατάλληλη για εικόνες, επειδή οι συνελικτικές στρώσεις μπορούν να μάθουν τοπικά χαρακτηριστικά, όπως γραμμές, καμπύλες και γωνίες, χωρίς να χαθεί η χωρική πληροφορία της εικόνας.

## Οδηγίες εκτέλεσης
1. Ανοίξτε το αρχείο `MNIST_Deep_Learning_Assignment.ipynb` στο Google Colab.
2. Επιλέξτε Runtime > Run all.
3. Περιμένετε να ολοκληρωθούν τα πειράματα και η εκπαίδευση του CNN.
4. Κατεβάστε ή κρατήστε τα παραγόμενα αρχεία CSV για την τεχνική έκθεση.
5. Συμπληρώστε στο τελικό έγγραφο το Colab URL και το GitHub Repository URL.
